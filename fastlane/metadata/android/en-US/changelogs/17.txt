Fix imported images showing "0 B" and being immediately deselected on
the main screen.

Imported images resolve to root-only paths (/data/media/0 or
/mnt/pass_through/0) so the kernel USB gadget can read them, but the
app process cannot stat those paths. Plain File.exists()/File.length()
therefore returned false/0, which cleared the selection and displayed a
wrong size. All UI-side existence checks, size lookups, deletes and
renames now fall back to a root shell automatically (new RootFileOps
helper); the image list prefetches sizes in a single batch stat call.
